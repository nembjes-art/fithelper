# FitHelper

Личное приложение для похудения. Работает в браузере, ставится на домашний экран iPhone как обычное приложение.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | Каркас приложения |
| `js/store.js` | Хранение данных (память браузера) |
| `js/engine.js` | Вся математика: калории, расход, тренд веса, стратегия |
| `js/gemini.js` | Распознавание еды по фото через Google Gemini |
| `js/ui.js` | Помощники интерфейса |
| `js/app.js` | Экраны и логика |
| `sw.js` | Офлайн-режим |
| `css/style.css` | Оформление |

Данные хранятся **только на твоём телефоне**. Никакого сервера нет. Фото уходит напрямую в Google Gemini по твоему ключу и нигде не сохраняется.

## Запуск: 5 минут

### 1. Выложить на GitHub Pages

```bash
cd C:\Users\nembj\Desktop\fithelper
git init
git add .
git commit -m "FitHelper"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/fithelper.git
git push -u origin main
```

Затем на github.com в репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.**

Через минуту приложение будет на `https://ТВОЙ_ЛОГИН.github.io/fithelper/`

> Репозиторий можно сделать приватным — но тогда Pages требует платный план. Проще оставить публичным: в коде нет ни одного твоего данного, ключ Gemini вводится в приложении и хранится только на телефоне.

### 2. Получить ключ Gemini

Открой [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key** → скопируй.

### 3. Поставить на iPhone

1. Открой ссылку **в Safari** (не в Chrome — иначе не установится)
2. Кнопка «Поделиться» → **На экран «Домой»**
3. Запусти с иконки
4. Заполни анкету
5. **Итоги → Настройки → вставь ключ Gemini → Проверить → Сохранить**

Готово.

## Как обновлять

Правишь файлы на компьютере → `git add . && git commit -m "правка" && git push` → через минуту обновится на телефоне. Данные при обновлении не теряются.

## Резервная копия

**Настройки → Выгрузить** сохраняет всю историю в JSON. Делай раз в неделю: если Safari почистит данные сайтов, история веса и еды пропадёт. Восстановление — **Загрузить**.

## Как считается стратегия

1. **Базовый обмен** — формула Миффлина — Сан Жеора по росту, весу, возрасту и полу.
2. **Расход** — базовый обмен × 1.20 + калории от шагов. Тренировки в расход **не** заложены намеренно: они дают дефицит сверху плана, поэтому факт обгоняет прогноз, а не отстаёт.
3. **Лимит калорий** — расход минус 30% (но не больше 1000 ккал дефицита). Есть жёсткий пол: не ниже 1500 ккал и не ниже 80% базового обмена. Глубже — горят мышцы, а не жир.
4. **Через 2 недели** записей движок перестаёт верить формуле и считает **реальный** расход по факту:
   `расход = средний приход − (изменение тренда веса × 7700) / дней`
   Дальше стратегия строится на этой цифре, а не на теории.
5. **Тренд веса** — среднее за 7 дней. Дневной вес скачет на 1–2 кг от воды и соли; решения принимаются только по тренду.
6. **Потолок безопасности** — не больше 1.5% массы тела в неделю.
